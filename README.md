# Vips

Vips — приложение для напоминаний на Android 13 и новее. Записывайте дела текстом или голосом, настраивайте повторы и смотрите ближайшие напоминания на виджете.

Скачайте APK в разделе [Releases](https://github.com/theekairo/Vips-releases/releases/latest). При установке новой версии поверх предыдущей напоминания и настройки сохраняются.

В приложении обновления доступны в разделе **Настройки → О приложении → Проверить обновления**. Для разбора текста с помощью ИИ потребуется личный ключ DeepSeek, который можно добавить в настройках приложения.
