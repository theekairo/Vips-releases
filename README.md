# Vips

Готовое приложение-напоминалка для Android 13 и новее.

Скачайте APK в разделе [Releases](https://github.com/theekairo/Vips-releases/releases/latest).
При установке новой версии поверх старой напоминания сохраняются.

В самом Vips обновления проверяются при открытии. Ручная проверка:
**Настройки → О приложении → Проверить обновления**.
Нажмите **Обновить**, дождитесь загрузки, затем **Установить**.
При первом обновлении Android попросит разрешить установку из Vips.

В репозитории публикуются только готовые APK, информация об обновлениях и эта инструкция.
Исходного кода и ключей здесь нет.

Для добавления напоминаний с ИИ на новом телефоне нужен личный ключ DeepSeek;
он указывается в разделе «О приложении → Настроить доступ к ИИ».
